受講前 環境構築手順書（Windows）

対象読者本トレーニング（全 5 回）を受講される方 所要時間30 分〜1 時間 実施時期第 1 回の受講日までに完了

目次

    このドキュメントについて

    GitHub Copilot ハンズオントレーニング（全 5 回）を受講するための、受講前の環境構築手順書です。

    前提条件

    項目内容
    OSWindows 10（21H2 以降）／ Windows 11。本トレーニングは Windows を前提としています
    GitHub Copilot ライセンス付与済みであることを前提としています（組織契約 Business / Enterprise）
    GitHub アカウントライセンスが紐づいているアカウントでサインインできること
    PC の権限ソフトウェアのインストールができること
    ネットワークインターネット接続できること

    セットアップ全体の流れ

    STEPやること目安
    STEP 1必須ソフトウェアの導入（Python / Git / VS Code / ブラウザ）20 分
    STEP 2PowerShell の実行ポリシー設定と VS Code 拡張機能の導入10 分
    STEP 3GitHub Copilot のサインインと有効化確認5 分
    STEP 4教材の展開と Python 環境の構築10 分
    STEP 5動作確認（Python 環境と Copilot が動くかの最低限の確認）5 分

    本書で使うターミナルについて

    本書のコマンドはすべて PowerShell を前提としています。次のいずれかで起動してください。

    • スタートメニューで「PowerShell」または「ターミナル（Windows Terminal）」を検索して起動
    • STEP 4 以降は VS Code のターミナル（メニューの ターミナル → 新しいターミナル）でも構いません

    STEP 1：必須ソフトウェアの導入

    目的ハンズオンで使う 4 つのソフトウェアを、指定バージョン以上で揃える 目安20 分

    すでに入っている場合は、バージョンだけ確認して条件を満たしていれば再インストールは不要です。

    ツール必要バージョン入手先確認コマンド
    Python3.13.14（64-bit）
    ※3.11 / 3.12 / 3.13 系が既に入っていれば入れ直し不要    		python.org（3.13.14）python --version
    Git2.40 以上git-scm.comgit --version
    VS Code1.106 以降（必須）code.visualstudio.comcode --version
    ブラウザChrome / Edge OS 標準の Edge で可
    VS Code は 1.106 以降が必須です 第 3 回で使う Plan モードが VS Code 1.106 で導入された機能のため、これより古いと演習ができません。すでに VS Code をお使いの方も、必ずバージョンを確認してください。

    1-1. Python

    1. Python 3.13.14 のダウンロードページを開き、ページ下部の Files 表にある 「Windows installer (64-bit)」をクリックしてインストーラをダウンロードします。
    2. インストーラを起動し、最初の画面で 「Add python.exe to PATH」にチェックを入れます。これを忘れると、あとで python コマンドが見つからなくなります。
    3. Install Now をクリックしてインストールします。
    4. PowerShell を開き直して、次のコマンドでバージョンを確認します。
    python --version
    Python 3.13.14

    1-2. Git

    1. git-scm.com から Windows 用インストーラ「Git for Windows/x64 Setup.」をダウンロードします。
    2. インストーラの設定はすべて既定のままで問題ありません。改行コードの選択画面では既定の 「Checkout Windows-style, commit Unix-style line endings」のままで構いません。
    3. PowerShell を開き直して、バージョンを確認します。
    git --version
    git version 2.47.1.windows.1

    Git 初回設定として、名前とメールアドレスを設定します。これを飛ばすと STEP 4 の git commit が Please tell me who you are というエラーで失敗します。すでに設定済みの方（git config --global user.name で名前が表示される方）は不要です。

    git config --global user.name "Your Name"
git config --global user.email "you@example.com"

    1-3. VS Code 1.106 以降

    1. code.visualstudio.com から Windows 用インストーラ（User Installer で可）をダウンロードします。
    2. インストーラの「追加タスクの選択」画面で、「PATH への追加」と「エクスプローラーのディレクトリ コンテキスト メニューに『Code で開く』アクションを追加する」の両方にチェックを入れます。
    3. PowerShell を開き直して、バージョンを確認します。
    code --version
    1.108.2
b7c4e1f9a2d3c5e8f0a1b2c3d4e5f6a7b8c9d0e1
x64

    すでに VS Code を使っていてバージョンが古い場合は、VS Code を起動して ヘルプ → 更新の確認（Help → Check for Updates）からアップデートしてください。

    1-4. ブラウザ

    第 2 回のテトリス、第 3 回の TODO アプリの動作確認でブラウザを使います。ChromeまたはEdgeのブラウザが入っているか確認してください。

    STEP 1 チェックポイント
    • python --version が 3.13.14（既存環境の場合は 3.11 以上）を表示する
    • git --version が 2.40 以上を表示する
    • code --version の 1 行目が 1.106 以上を表示する
    • Chrome または Edge の最新版が使える

    STEP 2：PowerShell と VS Code の初期設定

    目的Python 仮想環境を有効化できるようにし、ハンズオンで使う VS Code 拡張機能を入れる 目安10 分

    2-1. PowerShell の実行ポリシーを変更する

    STEP 4 で作る Python 仮想環境は、Activate.ps1 というスクリプトで有効化します。Windows の既定設定ではこのスクリプトの実行がブロックされるため、あらかじめ実行ポリシーを変更しておきます。

    Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

    確認メッセージが出たら Y を入力してエンターキーを押します。設定できたかは次のコマンドで確認できます。

    Get-ExecutionPolicy -Scope CurrentUser
    RemoteSigned
    -Scope CurrentUser を付けているため、影響範囲はログインしている自分のユーザーだけです。管理者権限も不要です。

    2-2. VS Code 拡張機能を確認する

    VS Code を起動し、左端のアクティビティバーから拡張機能（四角が 4 つ並んだアイコン）を開きます。インストールが必要なのは Python だけです。

    インストールするもの

    拡張機能拡張機能 ID用途
    Python（Microsoft 公式）ms-python.pythonPython の実行・補完・仮想環境の認識

    Python 拡張をインストールすると、Pylance（補完）・Python Debugger・Python Environments も自動で一緒に入ります。個別にインストールする必要はありません。

    確認するだけでよいもの（VS Code に同梱済み）

    拡張機能拡張機能 ID用途
    GitHub CopilotGitHub.copilot-chatコード補完（ゴーストテキスト）とチャット・Ask / Agent / Plan（全回）

    拡張機能タブで 「Copilot」と検索し、「インストール済み」と表示されていれば作業は不要です。VS Code 1.106 以降では補完とチャットが 1 つの拡張に統合され、VS Code 本体に同梱されています。実際に使えるようにする作業は、次の STEP 3（サインイン）で行います。

    以前から VS Code をお使いで、旧バージョンの補完専用拡張（GitHub.copilot）が別に入っている場合も、そのままで構いません（アンインストール不要です）。

    Python をインストールしたら、コマンドパレット（Ctrl+Shift+P）を開き、Developer: Reload Window を実行して VS Code を読み込み直してください。

    STEP 2 チェックポイント
    • Get-ExecutionPolicy -Scope CurrentUser が RemoteSigned を返す
    • 拡張機能タブで Python が「インストール済み」になっている
    • 拡張機能タブで GitHub Copilot が「インストール済み」になっている（同梱済みのため、通常は最初から）
    • Developer: Reload Window を実行した

    STEP 3：GitHub Copilot のサインインと有効化確認

    目的付与済みライセンスで Copilot にサインインし、当日使う 3 つのモードが選べる状態にする 目安5 分

    ライセンスは事前に付与されている前提です。ここではそのライセンスが自分の VS Code で有効になっていることを確認します。

    3-1. Copilot にサインインする

    1. VS Code の右下のステータスバーにある GitHub Copilot アイコンをクリックします。
    2. メニューから Sign in を選ぶとブラウザが開くので、ライセンスが付与されている GitHub アカウントで認証します。
    3. VS Code に戻り、右下のアイコンがグレーではなく有効な状態（青系の表示）になっていることを確認します。

    3-2. ライセンスが有効か確認する

    ブラウザで github.com/settings/copilot を開き、組織経由のアクセス（Business / Enterprise）が表示されることを確認します。

    3-3. モードピッカーを確認する

    VS Code のサイドバーからチャットアイコン（または Ctrl+Alt+I）で GitHub Copilot Chat を開き、入力欄の下にあるモードピッカーを確認します。

    モード使う回確認タイミング
    Ask第 1 回〜第 1 回までに必須
    Agent第 2 回〜第 1 回までに必須
    Plan第 3 回第 3 回までに必須（VS Code 1.106 以降で表示されます）
    STEP 3 チェックポイント
    • VS Code 右下の Copilot アイコンが有効な状態で表示されている
    • github.com/settings/copilot で組織経由のライセンスが確認できる
    • チャットのモードピッカーで Ask / Agent が選べる（第 1 回必須）
    • モードピッカーに Plan がある（第 3 回必須。無ければ事務局へ連絡）

    STEP 4：教材の展開と Python 環境の構築

    目的教材 ZIP を展開し、ハンズオンで使う Python の依存パッケージを入れる 目安10 分

    4-1. 教材 ZIP を展開する

    配布された github-copilot-training.zip を、任意のフォルダーに展開します。展開すると github-copilot-training フォルダーができます。

    展開先の選び方（Windows でのつまずきを避けるため）
    • パスに日本語やスペースを含めない（例：C:\handson\ の直下が安全です）
    • 階層を深くしすぎない（Windows のパス長制限に引っかかることがあります）
    推奨：C:\handson\github-copilot-training

    ZIP を右クリック →「すべて展開」で展開できます。展開前に右クリック →「プロパティ」で「セキュリティ：このファイルは他のコンピューターから…」の表示があれば「許可する」にチェックしておくと、ファイルがブロックされずに済みます。

    4-2. VS Code でフォルダーを開く

    1. VS Code を起動し、ファイル → フォルダーを開く から、展開した github-copilot-training フォルダーを選びます。
    2. 「このフォルダー内のファイルの作成者を信頼しますか?」と聞かれたら、「はい、作成者を信頼します」を選びます。信頼しないと Copilot の一部機能が動きません。
    3. メニューの ターミナル → 新しいターミナル でターミナルを開きます。ここが以降の作業場所になります。

    VS Code のターミナルが PowerShell 以外（cmd 等）で開く場合は、ターミナル右上の ＋ の横にある「∨」から PowerShell を選んで開き直してください。

    4-3. Git 管理の開始と Python 仮想環境の構築

    次のコマンドを上から順に実行します。git init 以降の 3 行は、第 2 回・第 3 回で「Copilot が何を書き換えたか」を git diff で見比べるための準備です。

    cd C:\handson\github-copilot-training

git init
git add -A
git commit -m "初期状態"

python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt

    1 行目の cd は展開先に合わせて読み替えてください。VS Code でフォルダーを開いた状態のターミナルなら、すでにそのフォルダーにいるので cd は不要です。

    仮想環境が有効になると、ターミナルのプロンプト先頭に (.venv) が付きます。

    (.venv) PS C:\handson\github-copilot-training>

    pip install で入るのは次の 4 つです。

    パッケージ用途
    pytest第 2 回のテスト生成ハンズオンで実行するテストフレームワーク
    pytest-cov同上（カバレッジ計測）
    flask第 3 回の TODO アプリ（Web サーバ）と第 4 回の Skill ハンズオン
    ruff第 5 回の Harness ハンズオン⑥で使うコード検査ツール（バージョン 0.17.0）
    第 4 回（Skill ハンズオン）を受講される方へ 第 4 回の Skill ハンズオンで Flask アプリを使う方も、この STEP 4 の手順で環境を準備してください。すでに完了している場合は、追加の Flask 導入は不要です。演習では、教材フォルダー直下の .venv を引き続き使用します。
    ターミナルを開き直したら、毎回 (.venv) の確認を 仮想環境の有効化はそのターミナルだけに効きます。新しいターミナルを開いたときは、次のコマンドで有効化し直してください。研修当日も同じです。 
    .venv\Scripts\Activate.ps1
    STEP 4 チェックポイント
    • github-copilot-training フォルダーを VS Code で開いている（左のエクスプローラーに samples と portable が見える）
    • ターミナルのプロンプト先頭に (.venv) が付いている
    • pip install -r requirements.txt がエラーなく完了した
    • git commit -m "初期状態" が成功した

    STEP 5：動作確認

    目的Python 環境と Copilot が動くことを、最低限だけ確認する 目安5 分

    ここからのコマンドは、すべて (.venv) が付いたターミナルで、教材フォルダーの直下で実行してください。

    5-1. Python 環境の確認

    次の 4 行をまとめて実行します。バージョンが表示され、最後に小さなテストウィンドウが開けば OK です。ウィンドウを閉じるとプロンプトに戻ります（閉じるまで次のコマンドは打てません）。

    pytest --version
flask --version
    python -m ruff --version
python -m tkinter
    pytest 8.3.4
Python 3.13.14
Flask 3.1.3
Werkzeug 3.1.8
ruff 0.17.0

    pytestが見つからない、またはNo module named ruffと出る場合は、(.venv)が付いたターミナルか、STEP 4で依存関係を導入済みかを確認してください。No module named 'tkinter' と出る場合は、Python 公式インストーラで「tcl/tk and IDLE」を含めて入れ直すと解決します。

    ここがいちばん重要な確認です。実際に Copilot が反応するかを見ます。

    1. 教材フォルダーを開いた VS Code で Ctrl+Alt+I を押してチャットを開き、モードが Ask になっていることを確認して、次のプロンプトを送ります。 
      こんにちは
    2. 日本語で返答がくれば、チャットは正常です。
    STEP 5 チェックポイント
    • pytest --version と flask のバージョンが表示される
    • python -m tkinter でテストウィンドウが開く
