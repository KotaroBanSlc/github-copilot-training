## 外部移行ツールとの互換性

- `_legacy_normalize_title`は、別管理のCSV移行ツールが関数名を指定して利用している想定です。
- 対象フォルダー内にそのツールのソースはなく、アプリ内の参照検索だけでは利用を確認できません。
- 移行完了後に廃止する予定ですが、完了の確認記録はまだありません。現時点では保持が必要です。
- 「廃止予定」は「廃止済み」ではありません。削除を検討するには、移行完了と利用終了の確認が必要です。

## 旧計算機能の廃止

- `import math`は旧計算機能の名残です。その機能は廃止済みで、互換性や初期化のためにimportを残す要件はありません。
- この記載だけで削除を決めず、現在のコードでも参照がなく、副作用や登録への影響がないことを確認してください。
